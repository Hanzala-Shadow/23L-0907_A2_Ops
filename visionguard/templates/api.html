Image classification API

Another perspective on your image.

Check visual patterns associated with AI-generated and real images. Receive a likely class and a confidence score.

Use the API

View service health or send an image to POST /predict with your API key.

curl {{ api_origin }}/predict \
  -H "X-API-Key: $VISIONGUARD_API_KEY" \
  -F "image=@photo.png"

JPEG, PNG or WebP. Maximum 4 MiB and 4 million pixels. Images are processed in memory and are not stored by this API. Keep your API key private.

A model's opinion, not proof of origin. Results can be wrong and cannot establish an image's authenticity.
